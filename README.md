# ProofLine

Cryptographic identity layer for B2B financial communications. 
Prevents wire fraud through hardware-backed signing and on-chain 
anchoring.

See `docs/PRD.md` and `docs/TDD.md` for product and technical 
specs. See `docs/design-reference/README.md` for the visual 
design source.

## Quick start

    pnpm install

Then read `docs/SETUP.md` (added in a later commit).
