## 5. Run / build / deploy

```bash
pnpm install
pnpm --filter @proofline/<pkg> test        # e.g. @proofline/extension-chrome, @proofline/functions
pnpm --filter @proofline/<pkg> typecheck
pnpm --filter @proofline/extension-chrome build   # → apps/extension-chrome/dist
```

- **Extension:** build, then load/reload `apps/extension-chrome/dist` unpacked at `chrome://extensions` (Developer mode).
- **Deploy to prod `proofline-cdabb`** (Daniel):
  ```bash
  firebase deploy --only functions          # functions:api; packages/email bundles in
  firebase deploy --only hosting:admin       # web-admin
  firebase deploy --only hosting:sign        # web-sign
  ```
  `web-verify` / `web-counterparty` were not changed in this batch — no redeploy needed.

## 6. Gotchas

- **Deploy secret prompts:** enter `placeholder` where a real key isn't set yet (the real ones are PFL-211). The function fails closed on a real call until the secret is set.
- **esbuild env promotion:** the functions build reads `apps/functions/.env` (merged over repo-root `.env.local`) → `dist/.env`. A `PROOFLINE_ENV=production|staging` build **fails** if `PROOFLINE_ENV` / `EMAIL_PROVIDER` / `ANCHOR_PROVIDER` / `KMS_PROVIDER` are missing (by design).
- **Hosting:** use `--only hosting:<target>`; the targets are `admin` / `sign` / `verify` / `counterparty` (`.firebaserc`).
- **Extension reload:** reload the unpacked `dist/` after every build — Chrome does not hot-reload it.
- **WebAuthn RP:** passkeys are bound to RP `proofline-sign.web.app`. Biometric steps only work where web-sign is served at that RP — this is why the PFL-136/146 biometric staging steps can't run until PFL-189/an RP-matching env exists.
- **Acme demo data:** `testCompany=true` + `gmail.com` in `allowedFromDomains`. **Until reset (PFL-210), the verify page shows the yellow "Test company" banner for Acme.**
- **Mobile-web Gmail** is NOT covered by the client guard (known gap) — server-side enforcement (PFL-193) is the backstop.
- **Board tooling:** no group-create MCP tool, so **Phase 12** is `sprint = "Phase 12"` + tag `phase-12` (not a real column); dependencies are written as "Blocked by PFL-xxx" in card notes (no `link_tasks`); duplicate empty groups can't be removed from here (tracked in PFL-212).
